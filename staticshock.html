StaticShock

Local helper to build the GitHub Secrets commands for the Journali repository. This page runs entirely in your browser and does not send values anywhere.

Security reminder: Prefer pasting .p8 files directly into the GitHub Secrets UI or use the gh CLI with a file path. Do not paste secrets into unknown pages. This tool is safe to run locally from this repository copy.

Generated commands

You can run these with the GitHub CLI (gh) on a machine with gh logged in as a repo admin. They will set repository secrets for zonagreentea/Journali.
(press Generate)
Tip: for the APP_STORE_CONNECT_PRIVATE_KEY it's safer to use the CLI and a file: gh secret set APP_STORE_CONNECT_PRIVATE_KEY --body "$(cat /path/to/AuthKey_XXXX.p8)" --repo zonagreentea/Journali
